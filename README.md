# Aastha Care - Elder Health & Safety Web Companion

An elder-friendly health dashboard designed for simplicity, clarity, and accessibility, powered by **Sarvam AI** (`sarvam-105b-conversations`).

## Features Specifically Designed for Elders

- **No Hidden Buttons or Menus**: Everything is laid out directly on the main screen in clear, prominent cards.
- **Large High-Contrast Text**: Big readable labels, high-contrast borders, and quick `[A-] [A] [A+]` text-scaling buttons.
- **1-Tap Emergency SOS**: Immediate family and caregiver alert button with location dispatch.
- **Today's Medicine Timetable**: Clear morning, afternoon, and night cards with 1-tap "Mark Taken" buttons.
- **Live Smartwatch Vitals**: Real-time heartbeat (BPM) monitor and daily step progress ring.
- **Biometric Evaluation**: Easy input for Blood Pressure and Sugar with instant color-coded explanations (Normal, Attention Needed).
- **Weekly Health Tracker**: Monday-Sunday adherence records and 7-day averages.
- **Inbuilt GPS Safe Zone Tracker ("Where Am I?")**: Displays home safe zone, current address, and speaks directions aloud.
- **Sarvam AI Voice Assistant**: Listens and responds in simple Hindi or English with warm, compassionate medical advice.

## How to Run

### 1. Launch the Web Application
```powershell
python app.py
```
Open **[http://localhost:8080](http://localhost:8080)** in your browser.

### 2. Launch the CLI Chatbot (Optional)
```powershell
python chat_cli.py
```
